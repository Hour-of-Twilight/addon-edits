# Hour of Twilight Compatible Addons

A collection of World of Warcraft addons patched to work with the **Hour of Twilight** private server. Hour of Twilight has custom class and spell changes that can break standard addon behavior — this repo tracks the fixes applied to make these addons compatible.

## Addons

### Bagnon Suite

- **Bagnon** — Unified bag/inventory viewer
- **Bagnon_Config** — Configuration UI for Bagnon
- **Bagnon_Forever** — Caches inventory data for offline viewing
- **Bagnon_GuildBank** — Extends Bagnon to the guild bank
- **Bagnon_Tooltips** — Adds cross-character item count tooltips

### Details Suite

- **Details** — Damage/healing meter
- **Details_3DModelsPaths** — 3D model path data for Details
- **Details_ChartViewer** — Chart display plugin
- **Details_DataStorage** — Persistent data storage for Details
- **Details_DeathGraphs** — Death log and graph display
- **Details_EncounterDetails** — Per-encounter breakdown
- **Details_SunderCount** — Sunder Armor application tracker
- **Details_TimeLine** — Timeline display plugin
- **Details_TinyThreat** — Compact threat display

### ElvUI Suite

- **ElvUI** — Comprehensive UI replacement framework
- **ElvUI_AddOnSkins** — Skins other addons to match ElvUI
- **ElvUI_CustomTags** — Additional unit frame text tags
- **ElvUI_CustomTweaks** — Extra ElvUI configuration options
- **ElvUI_Enhanced** — Feature enhancements for ElvUI
- **ElvUI_OptionsUI** — ElvUI configuration panel
- **ElvUI_ToxiUI** — ToxiUI profile/layout for ElvUI

### Other

- **CompactRaidFrame** — Compact raid unit frames
- **HoT_UIBridge** — Custom bridge addon for Hour of Twilight server-specific APIs
- **pw_unitframes** — Alternative unit frame addon

## Installation

1. Clone or download this repository.
2. Copy the addon folders you want into your WoW `Interface/AddOns/` directory:
   ```
   World of Warcraft/Interface/AddOns/
   ```
3. Launch Hour of Twilight and enable the addons in the character select screen.
