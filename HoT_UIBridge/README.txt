HoT UI Bridge

What it does:
- Adds Hour of Twilight bag upgrade arrows to ElvUI bags and Bagnon
- Adds upgrade tooltip lines to item tooltips
- Replaces progression display for ElvUI nameplate levels
- Adds progression level overlays to ElvUI player/target/focus/targettarget unitframes

Install:
1. Close WoW
2. Copy the HoT_UIBridge folder into Interface/AddOns/
3. Start the game and enable HoT UI Bridge at character select
